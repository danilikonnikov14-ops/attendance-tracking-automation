Что представляет себя данный проект:
Автоматический учёт посещаемости студентов через распознавание лиц. Староста заходит в мобильное приложение фотает группу на паре, бэкенд распознает лица и отмечает кто присутствует, а кто нет. Декан заходит на сайт и смотрит полную статистику, так же может скачать графики и данные через экспорт на выбор - pdf/excel. У администратора есть админ панель с дашбордом, добавлением и удалением пользователей, групп, студентов.

Система автоматически парсит расписание с официального сайта колледжа. Расписание обновляется в фоновом режиме.

Безопасность - JWT-авторизация, ролевая модель, хеширование паролей, защита от SQL-инъекций.

В данный момент распознавание лиц не работает, тк сервер слабый, в ближайшее время я арендую сервер помощнее и распознание будет работать, после чего будут добавлены тесты

Так же в будущем планирую перейти с flask на FastAPI, улучшить безопасность, добавить миграции, дополнить обработку ошибок, где ее не хватает и добавить документирование
